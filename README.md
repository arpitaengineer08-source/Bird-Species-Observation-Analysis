# Bird Species Observation Analysis

An end-to-end data analysis project exploring bird observations across forest and grassland habitats. The workflow combines data preparation, exploratory analysis and an interactive dashboard to make observation patterns easier to investigate.

## Project files

| File | Purpose |
|---|---|
| `Bird_Species_Analysis.ipynb` | Data loading, cleaning, exploratory analysis and visualisations |
| `streamlit_dashboard.py` | Interactive dashboard built with Streamlit and Plotly |
| `Bird_Monitoring_Data_FOREST.XLSX` | Forest habitat source workbook |
| `Bird_Monitoring_Data_GRASSLAND.XLSX` | Grassland habitat source workbook |
| `Bird_Combined_Cleaned.csv` | Combined, cleaned dataset generated by the notebook |
| `requirements.txt` | Python dependencies |

## Data preparation

The notebook consolidates the forest and grassland workbooks and prepares a consistent dataset for analysis.

Documented preparation steps include:

- Combining 11 sheets from each workbook (22 sheets in total, with empty sheets skipped).
- Aligning column names and schemas across the source files.
- Removing 1,705 exact duplicate rows.
- Removing `Sub_Unit_Code`, a column with more than 90% missing values.
- Assigning explicit labels to missing values in selected categorical fields.
- Parsing dates and deriving month and season fields.

The original Excel workbooks are retained as source data.

## Interactive dashboard

The Streamlit dashboard supports filtering and exploration by:

- Habitat
- Administrative unit
- Year
- Season
- Watchlist

It uses Plotly charts to present the selected observations.

## Run locally

### 1. Install dependencies

```bash
pip install -r requirements.txt
```

### 2. Run the analysis notebook

Open `Bird_Species_Analysis.ipynb` in VS Code or Jupyter, select a Python kernel and run the notebook from top to bottom.

### 3. Launch the dashboard

```bash
streamlit run streamlit_dashboard.py
```

## Analysis workflow

`Source workbooks → Data consolidation → Cleaning and standardisation → Exploratory analysis → Interactive dashboard`
