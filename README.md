# Bird Species Observation Analysis — VS Code Setup

## Files
- `Bird_Species_Analysis.ipynb` — full pipeline: load → clean → EDA → charts (tested, runs top-to-bottom)
- `streamlit_dashboard.py` — interactive Plotly dashboard (filters, KPIs, charts)
- `Bird_Monitoring_Data_FOREST.XLSX`, `Bird_Monitoring_Data_GRASSLAND.XLSX` — raw source data (keep as-is)
- `Bird_Combined_Cleaned.csv` — cleaned dataset generated by the notebook (also included pre-generated)
- `requirements.txt` — Python packages needed

## How to run in VS Code

1. Sab files ek hi folder mein rakho (notebook + both XLSX files together).
2. Terminal mein (VS Code ke andar) yeh chalao:
   ```bash
   pip install -r requirements.txt
   ```
3. **Notebook chalane ke liye:**
   - `Bird_Species_Analysis.ipynb` ko VS Code mein open karo.
   - Install the "Jupyter" extension if not already installed.
   - Top-right mein kernel select karo (Python 3.x).
   - "Run All" click karo — yeh data load, clean karega, aur saare EDA charts inline dikhayega. End mein `Bird_Combined_Cleaned.csv` save ho jayegi.

4. **Interactive dashboard chalane ke liye** (Streamlit):
   ```bash
   streamlit run streamlit_dashboard.py
   ```
   Yeh browser mein ek local dashboard open karega with filters (Habitat, Admin Unit, Year, Season, Watchlist) aur interactive Plotly charts.

## What was done (summary)
- Combined 11 sheets each from Forest + Grassland workbooks (22 sheets total, empty sheets skipped).
- Unified column naming (`NPSTaxonCode` → `TaxonCode`), aligned schemas.
- Removed 1,705 exact duplicate rows.
- Dropped a >90%-empty column (`Sub_Unit_Code`).
- Filled missing `Sex`, `Distance`, `ID_Method` with explicit labels instead of blank.
- Parsed dates, derived `Month`, `Month_Name`, `Season`.
- Converted numeric and boolean columns to proper dtypes.
- Dropped rows with no identified species.
- Final cleaned dataset: **15,372 rows**, 127 unique species (108 Forest / 107 Grassland).
- EDA covers: seasonal/yearly trends, observation time windows, admin-unit & plot hotspots, species diversity & activity/ID methods, sex ratio, temperature/humidity/sky/disturbance correlation, distance & flyover behavior, observer trends, and PIF Watchlist conservation priorities (8 watchlist species, 378 observations).
